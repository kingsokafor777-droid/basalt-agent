# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-08-19

### Added

- Safety-first Terraform remediation plans for five literal Basalt IaC rules.
- Isolated staging, source-hash guards, source-root confinement, and deterministic diff generation.
- Basalt IaC re-analysis that fails closed when the target rule remains or scanner errors occur.
- Local pull-request artifact bundles with a patch, plan, validation record, and reviewer-facing markdown.
- CLI, tests, CI, ADRs, examples, and package-quality controls.
